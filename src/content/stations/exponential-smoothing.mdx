Exponential smoothing is the workhorse of supply chain forecasting because it is fast, needs little data and runs well across thousands of items. Every version rests on one idea:

> new estimate = old estimate + α × (how wrong the last forecast was)

The smoothing constant α, between 0 and 1, sets how much the forecast reacts. A handy rule: the forecast effectively remembers about the last 1/α periods. With α = 0.1 it remembers about 10 periods and moves calmly; with α = 0.5 it remembers about 2 and reacts to every blip.

The family grows by adding pieces:

- **Simple exponential smoothing (SES)** tracks only the level, so its forecast is a flat line. Good for steady demand with no trend.
- **Holt's method** adds a trend, so the forecast becomes a sloped line.
- **Damped trend** lets that slope fade over time. This matters, because an undamped trend keeps rising for ever: a level of 100 growing by 10 a month forecasts 220 a year out, while a damped version settles below 200. For longer horizons, damping is usually the safer default.
- **Holt-Winters** adds seasonality, either **additive** (the seasonal swing is a fixed amount) or **multiplicative** (the swing is a percentage, so it grows as the business grows, which suits most retail and FMCG data).

**ETS** (error, trend, seasonal) wraps all of these into one statistical framework. Software can then pick the best version automatically and give prediction intervals as well as a single number.

<KeyIdea>

α is a memory dial: low α remembers long and moves slowly, high α reacts fast but chases noise. Add trend and seasonality only when the data shows them, and damp the trend for long horizons.

</KeyIdea>

<SayIt>

Exponential smoothing updates the forecast by a fraction α of the last error, so it weights recent data more. SES handles level only, Holt adds trend, damped trend stops the slope running away on long horizons, and Holt-Winters adds additive or multiplicative seasonality. ETS puts them in one statistical framework, so we can select the model automatically and get prediction intervals that feed safety stock.

</SayIt>

<Q q="What does a high α mean, and when is it a problem?">

A high α reacts strongly to the latest data, with an effective memory of about 1/α periods. That is good after a genuine level shift but bad when it chases random noise: forecasts jump around, planners lose trust and safety stock goes up. If an optimizer picks α near 1, check for a level shift or a missing trend first.

</Q>

<Q q="How do you tell additive from multiplicative seasonality?">

Plot the series. If the seasonal peaks stay the same size as the level rises, it's additive. If the peaks fan out as the series grows, it's multiplicative, which is typical of retail. Multiplicative models need strictly positive data, so they don't work for items with zero-demand periods.

</Q>
